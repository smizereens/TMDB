# TMDB Telegram Bot

**TMDB Telegram Bot** — учебный Telegram-бот для поиска и подбора фильмов с использованием TMDB API.

Бот позволяет искать фильмы по названию, просматривать популярные фильмы, фильмы с высоким рейтингом, ближайшие релизы и подбирать фильмы по жанру, году выпуска и рейтингу.

## О проекте

Проект демонстрирует работу с Telegram Bot API, внешним REST API, переменными окружения, обработкой пользовательских команд, inline-кнопками, reply-клавиатурой и пагинацией результатов.

Данные о фильмах загружаются из The Movie Database API. Бот отображает название, оригинальное название, дату выхода, жанры, продолжительность, рейтинг, описание и постер фильма, если он доступен.

## Функциональность

* Команда `/start` с приветствием и основной клавиатурой
* Команда `/help` со списком доступных действий
* Поиск фильмов по названию
* Подбор фильмов по критериям:

  * жанр
  * год выпуска
  * минимальный рейтинг
* Просмотр популярных фильмов
* Просмотр фильмов с высоким рейтингом
* Просмотр скоро выходящих фильмов
* Отображение постеров фильмов
* Пагинация результатов через inline-кнопки
* Обработка ошибок при запросах к API
* Хранение API-ключей в `.env`

## Команды бота

```text
/start      # запуск бота и вывод основной клавиатуры
/help       # справка по командам
/search     # поиск фильма по названию
/discover   # подбор фильма по критериям
/popular    # популярные фильмы
/toprated   # фильмы с высоким рейтингом
/upcoming   # скоро выходящие фильмы
/cancel     # отмена текущей операции
```

## Установка и запуск

### Требования

Перед запуском необходимо установить:

* Python 3.10+
* Telegram Bot Token
* TMDB API Token

### Клонирование репозитория

```bash
git clone https://github.com/smizereens/TMDB.git
cd TMDB
```

### Создание виртуального окружения

#### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

#### macOS / Linux

```bash
python3 -m venv venv
source venv/bin/activate
```

### Установка зависимостей

```bash
pip install -r requirements.txt
```

## Настройка переменных окружения

Создайте файл `.env` в корневой директории проекта:

```env
TELEGRAM_BOT_TOKEN=your-telegram-bot-token
TMDB_API_KEY=your-tmdb-api-token
```

Где:

* `TELEGRAM_BOT_TOKEN` — токен Telegram-бота, полученный через BotFather;
* `TMDB_API_KEY` — токен доступа к TMDB API.

Файл `.env` не должен попадать в Git.

## Запуск

```bash
python main.py
```

После запуска бот начнёт принимать сообщения в Telegram.

## Что реализовано

* Настроен запуск Telegram-бота через polling
* Реализована обработка команд `/start`, `/help`, `/search`, `/discover`, `/popular`, `/toprated`, `/upcoming`
* Добавлена основная reply-клавиатура для действий пользователя
* Реализован пошаговый подбор фильмов через ConversationHandler
* Добавлены inline-кнопки для выбора жанра и рейтинга
* Реализована пагинация результатов через inline-кнопки
* Добавен отдельный модуль для работы с TMDB API
* Реализована загрузка конфигурации TMDB API для отображения постеров
* Добавлена обработка ошибок API-запросов
* Настроена загрузка секретных ключей из `.env`
